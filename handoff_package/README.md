# PE Exit Analysis — Chart Reproduction Package

This package reproduces five specific charts from a larger private-equity exit
analysis project. It is a deliberately narrow slice of a much larger codebase:
only the data and code needed to regenerate these charts is included. Over the
course of the research, many iterations of the code/charts were made. This is 
isolated code and data for reproducibility.

## Target charts

| Chart | Script | Output |
|---|---|---|
| TP_Nested | `scripts/03_chart_tp_nested.py` | `output/figures/TP_Nested.png` |

## Setup

Use a dedicated virtual environment with the **pinned** versions in
`requirements.txt` — do not install into a system/global Python interpreter.

```bash
python -m venv .venv
.venv\Scripts\activate      # Windows
pip install -r requirements.txt
```

Requires a Chromium engine for Plotly's static image export (installed automatically
with `kaleido`).

Note: data/raw/pitchbook_export.xlsx` contains an
Excel AutoFilter with a blank filter criterion. Stable `openpyxl` (3.1.x)
parses this leniently, but pre-release/beta `openpyxl` builds (e.g. 3.2.0b1)
added stricter validation that raises 

`ValueError: Value must be eithernumerical or a string containing a wildcard` 

when reading this exact file.
If you hit that error, you're running against a different (likely
system-wide, possibly pre-release) Python/openpyxl install rather than this
project's pinned environment — check with:

```bash
python -c "import openpyxl, pandas; print(openpyxl.__version__, pandas.__version__)"
```

and confirm it reports `3.1.5` / `2.3.1`.

## How to run

Run scripts **in order** from the `handoff_package/` directory (each writes into
`data/clean/` or `output/figures/`):

```bash
python scripts/01_clean_pitchbook_master.py     # data/raw -> pitchbook_master_clean.parquet
python scripts/02_link_p2p_entry_exit.py        # data/raw -> p2p_linked_master.csv
python scripts/03_chart_tp_nested.py            # -> TP_Nested.png
python scripts/04_chart_trend_lines.py          # -> TP_Trend_Line.png, Total_Trend_Line.png
python scripts/05_chart_exit_composition_value.py  # -> exit_composition_entry_value_100pct.png
python scripts/06_chart_holding_period_se.py    # -> p2p_avg_holding_period_trend_se.png
```

Scripts 01 and 02 regenerate `data/clean/pitchbook_master_clean.parquet` and
`data/clean/p2p_linked_master.csv` from the raw PitchBook exports in
`data/raw/`. These regenerated files are already included for convenience, but
you can delete and re-run to confirm reproducibility.

### Two inputs are provided as-is, not regenerated by this package

- **`data/clean/non_tp_entry_exit_pairs.parquet`** — the Non-Take-Private
  entry/exit pairing. In the source project this comes from a separate,
  fuzzy-matching-based linking pipeline (`universe_linking.py` /
  `tp_linking.py` / `seperate_tp_universe_parquet.py`) that was out of scope
  for this package. It's shipped as a static input; only the TP + universe
  side of the pipeline is reproducible from raw data here.

- **`data/clean/p2p_linked_master_updated.csv`** — the same schema as
  `p2p_linked_master.csv` (produced by script 02) plus one additional column,
  `deal_type_exit_final`. That column reflects a manual review/enrichment
  step with no producing script in the source project. It's shipped as-is.
